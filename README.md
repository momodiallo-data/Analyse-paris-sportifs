# Analyse des paris sportifs

## Présentation du projet

Ce projet consiste à analyser un jeu de données fictif de transactions de paris sportifs sur la période de janvier à mars 2026.

L'objectif est d'exploiter les données afin d'identifier les tendances liées aux mises, aux sports, aux points de vente et aux statuts des transactions.

## Objectifs de l'analyse

- Analyser le volume et le montant total des mises.
- Comparer les mises selon les différents sports.
- Étudier la répartition des mises par point de vente.
- Observer l'évolution mensuelle des mises.
- Analyser la répartition des transactions selon leur statut.

## Outils utilisés

- Excel / Google Sheets : consultation et préparation des données.
- SQL (SQLite) : interrogation et analyse des transactions.
- Python (Pandas) : exploration et analyse des données.
- Looker Studio : création du tableau de bord interactif.

## Données utilisées

Le jeu de données contient 120 transactions fictives réparties sur trois mois : janvier, février et mars 2026.

Les principales variables sont :
- Date de transaction
- Client
- Type de pari
- Mise en FCFA
- Gain versé en FCFA
- Statut de la transaction
- Point de vente

## Principaux indicateurs

- Nombre de transactions : 120
- Total des mises : 474 000 FCFA
- Total des gains versés : 517 700 FCFA
